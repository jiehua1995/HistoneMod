# HistoneMod

`HistoneMod` provides a local Shiny application and a small programmatic
API for quantitative analysis of histone post-translational
modifications from Skyline-like peptide-level CSV exports.

## Details

Most users will start the interactive workflow with
[`runHistoneMod()`](https://jiehua1995.github.io/HistoneMod/reference/runHistoneMod.md).
The package also exports helper functions for preprocessing and plotting
in scripted analyses.
